# Zgłaszanie podatności

Podatności bezpieczeństwa zgłaszaj prywatnie przez GitHub: zakładka **Security → Report a vulnerability**
w tym repozytorium. Nie publikuj szczegółów podatności w publicznych zgłoszeniach (Issues).

W zgłoszeniu podaj: wersję programu, opis problemu, kroki do odtworzenia i możliwe skutki.
Nie dołączaj prawdziwych danych księgowych, osobowych ani sekretów (haseł, kluczy, tokenów KSeF).
