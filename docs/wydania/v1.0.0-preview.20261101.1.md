# Pełna Księgowość — 1.0.0-preview.20261101.1

Wydanie wstępne z poprawką konfiguracji PostgreSQL. Wersja aplikacji i instalatora pozostaje 1.0.0.

- Naprawiono `ManyServiceProvidersCreatedWarning` przy wielokrotnym tworzeniu kontekstów PostgreSQL: bezstanowy interceptor materializacji jest współdzielony przez konteksty EF Core.
- Dodano test regresji 32 konfiguracji PostgreSQL, sprawdzający współdzielenie usług bez otwierania połączenia.
- Poprawiono test obniżenia kapitału P.S.A., aby respektował format kwot właściwy dla języka systemu. Reguły księgowe nie uległy zmianie.

Poprawka nie zmienia schematu bazy ani wymagań dotyczących ograniczonego konta operatora PostgreSQL. Po zainstalowaniu należy ponownie uruchomić program i sprawdzić docelowy profil połączenia.

Windows: instalator MSI lub przenośny ZIP. Linux: DEB lub TAR.GZ. Integralność pobranych plików można sprawdzić za pomocą SHA256SUMS.txt.

Wydanie pochodzi z gałęzi `fix/postgres-service-provider-reuse` i nie jest scaleniem do `main`.
