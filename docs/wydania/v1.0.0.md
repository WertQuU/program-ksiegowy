# Pełna Księgowość 1.0.0

Program do prowadzenia pełnej księgowości (ksiąg rachunkowych) spółki — Windows i Linux, działa lokalnie, bez logowania
i bez wysyłania danych księgowych do twórców programu.

## Pobieranie i instalacja (Windows)

- **`PelnaKsiegowosc-1.0.0-x64.msi`** — instalator (zalecany). Uruchom i postępuj zgodnie z instrukcjami;
  program pojawi się w menu Start jako „Pełna Księgowość”.
- **`PelnaKsiegowosc-1.0.0-win-x64.zip`** — wersja przenośna: rozpakuj i uruchom `PelnaKsiegowosc.exe`.
- Linux: pakiety `.deb` i `.tar.gz`.
- `SHA256SUMS.txt` — sumy kontrolne plików.

Program nie jest podpisany certyfikatem wydawcy — Windows SmartScreen może wyświetlić ostrzeżenie
(„Więcej informacji” → „Uruchom mimo to”).

## Co zawiera

- Księgi: dziennik z ciągłą numeracją i nieusuwalnymi zapisami, plan kont z kreatorem, zamknięcia miesięcy i roku,
  bilans otwarcia, środki trwałe, magazyn, rozrachunki (także raty), bank i kasa, kontrahenci (biała lista, KRS, VIES).
- Podatki: VAT i JPK_V7M/V7K, KSeF (pobieranie i wysyłka faktur FA(3)), CIT z zaliczkami, podatek odroczony,
  JPK_CIT, podatek u źródła, odpisy aktualizujące i rezerwy.
- Kadry i płace: listy płac (umowa o pracę, zlecenie, dzieło, powołanie, PPK), nieobecności i urlopy, karta wynagrodzeń.
- Deklaracje i sprawozdania: wyliczenie CIT-8, VAT-UE, PIT-4R, PIT-8AR, PIT-11, IFT-2R, ZUS DRA/RCA (kwoty do
  przepisania), pliki XML VAT-UE/VAT-UEK/PIT-11 i e-Sprawozdania (walidowane schematami MF), uchwały roczne.
- Kreatory: pierwsze uruchomienie, plan kont, dodanie konta prostymi słowami, „Rozlicz miesiąc”, „Zamknij rok”,
  prosty wydatek/przychód; Pulpit z asystentem i terminami.

## Przed rozpoczęciem pracy

1. Uzupełnij dane spółki (e-mail, urząd skarbowy, województwo/powiat/gmina, PKD) i pracowników.
2. Plan kont i politykę rachunkowości przejrzy księgowy; zatwierdza je zarząd.
3. KSeF przetestuj najpierw w środowisku testowym MF.
4. Przez pierwszy miesiąc/kwartał prowadź księgi równolegle z dotychczasowym sposobem i porównaj wyniki.
5. Ustaw kopie zapasowe (sekcja Kopie) i sprawdź odtworzenie.
6. Pozycje oznaczone w rejestrze przepisów jako „do potwierdzenia” sprawdź w aktualnych przepisach (`docs/COMPLIANCE_MATRIX.md`).
